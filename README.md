# FirstItem

A Minecraft mod project built with Fabric. This project is my first step into Minecraft modding, focusing on creating custom items and learning the Fabric modding ecosystem.

## Features

- Custom Minecraft item
- Custom item texture
- Java-based mod development

## Requirements

- Minecraft version: 26.2
- Fabric Loader and the required Fabric dependencies
- Java version compatible with the project configuration

## Installation

1. Install Fabric Loader for the supported Minecraft version.
2. Download the mod JAR from the project's Releases page, when available.
3. Place the JAR file in your Minecraft `mods` folder.
4. Launch Minecraft using the Fabric profile.

## Development

This project is developed using Java and Fabric.

To build the mod locally, use the Gradle wrapper included in the repository:

```bash
./gradlew build
```

The generated JAR file will be available in `build/libs/`.

## Project Status

Early development. This project is being used to learn Minecraft modding and experiment with custom items.
